# ascii-generator

ascii-generator is an ASCII art generator using Rust.

More on ASCII art: https://en.wikipedia.org/wiki/ASCII_art

## Installation

Use the package manager [cargo](https://doc.rust-lang.org/cargo/getting-started/installation.html) to install ascii-generator (crate).

```bash
cargo install ascii-generator
```

## Usage

```bash
cargo run <path/to/image>

# example:
cargo run images/homer.png
```
